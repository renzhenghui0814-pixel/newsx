# NewsX Windows 悬浮组件

轻量的圆角无边框桌面小组件，使用 Tkinter 和用户提供的 TORA 行情 SDK。深色模式以模糊桌面背景呈现，浅色模式使用冷灰面板和近白卡片；首页展示自选行情、微博热搜和财联社头条，每张卡片最多展示 5 条，少于 5 条时按实际条数显示，展开页直接显示在面板上；窄窗口纵向滚动，宽窗口微博与财联社并排。默认窗口为 332×390，可拖动四边或四角调整到 900×960；支持深浅主题、透明度和拖动定位。

## 启动

本地构建后可双击 `release-news-weibo-inline-v3/NewsX.exe`；发布目录不纳入 Git。先前发布目录的 EXE 属于旧版；运行中的 EXE 无法直接覆盖。源码运行方式：Windows 10/11 安装 Python 3.10 或更新版本后，在项目目录双击 `NewsX.pyw`；也可以运行：

```powershell
python app.py
```

拖动顶部标题区可移动组件；鼠标移到四边或四角，指针变成双向箭头后可调整宽高。滚轮浏览三张卡片，点击卡片标题展开完整列表。鼠标移出时 Logo 与标题居中，移入时平滑移到左侧，同时显示主题、透明度和关闭按钮，图标悬停会显示提示。透明度按钮会在原地弹出竖向滑块。首页卡片没有状态栏；进入自选页后，底部左侧显示添加和站点按钮，右侧先显示站点连接状态，再显示行情更新时间（缓存行情会标明“缓存”）；热榜页底部左侧是刷新按钮。微博热搜第一名的序号、热搜值和标签使用红色。自选行情页名称前的橙色五角星可以切换关注，实心为已关注；首页只显示已关注的自选行情。点击行情行会原地进入五档详情，开盘与收盘、最高与最低、涨停与跌停、成交量与成交额分别同列对齐，从上至下显示卖5到卖1、买1到买5，鼠标移入面板时，右上角显示红色圆圈减号，可将股票移出自选并返回列表。`Ctrl+1/2/3` 分别展开自选、微博和财联社，`Ctrl+4` 也可展开财联社；方向键或滚轮浏览列表，`Ctrl+R` 刷新；Esc 关闭弹出框或返回卡片，不退出组件。设置保存在 `%APPDATA%\NewsXWidget\config.json`，自选项使用 `{"symbol":"SH600519","followed":true}` 格式。微博热搜每 10 分钟自动刷新。点击热搜条目会按微博移动端“综合”搜索结果的顺序原地展示前三条微博；长文默认只显示约 150 字，点“展开全文”可阅读完整正文。图片缩略图按三列铺满面板，点击后在文字下方展开大图，再次点击或选择“收起预览”即可折叠；点击视频中央的播放按钮会在原位播放；每条可在微博打开原帖，右上角图标打开热搜话题。点击财联社头条记录会在组件内展开新闻正文，右上角图标可打开财联社原文。

## 资讯来源

微博热搜优先读取微博官网榜单接口 `weibo.com/ajax/statuses/hot_band`，保持[官网热搜页](https://s.weibo.com/top/summary?cate=realtimehot)的正式名次，并过滤置顶项和无序号推广项。接口不可用时依次尝试官网热搜页及 [hot-search-crawler](https://github.com/solarhell/hot-search-crawler) 的 `latest.json` 快照，并在首页与展开页标明来源。热搜详情直接请求微博移动端“综合”搜索接口，先显示搜索结果，再异步补取长微博全文和图片；访客会话在后台预热，已打开的话题短时复用。视频按需下载并由嵌入面板的 mpv 播放，离开当前视频时停止。移动端结果与桌面官网在个性化或实时更新时可能略有差异。组件和财联社仍每 10 分钟请求一次，首页卡片显示本机最近一次成功获取时间；展开页显示数据源时间。来源异常时保留上次成功数据。旧配置中的默认第三方地址会自动迁移到官网接口；手动设置的其他兼容 JSON 地址继续可用。

财联社头条从[财联社官网头条栏目](https://www.cls.cn/depth?id=1000)读取，点击记录后再按需获取正文。行情、微博与财联社共同缓存在 `%APPDATA%\NewsXWidget\cache.json`；顶层是按平台分列的数组，每项采用 `{"platform":"weibo","time":"20261113-00:24:46","items":[]}` 格式。行情项额外保存交易日，微博项额外保存上游采集时间。首次启动会从旧版的独立缓存迁移，旧行情缓存因缺少逐只股票的交易日，仅迁移代码和名称。软件启动时先显示三份缓存及其时间，再在后台更新。

## 股票行情接口

已接入你提供的 `PythonAPI_v1.0.9_20260915.zip`。程序建立 TCP 长连接，登录后按交易所订阅自选代码，并用 SDK 推送的 `LastPrice` 和 `PreClosePrice` 计算涨跌幅。断线后由 SDK 重连，并重新登录订阅。登录或行情推送表明交易日变化时，旧行情的价格、涨跌幅、成交额、开高低收、五档等数值立即清空并写入缓存；股票代码和名称保留，新交易日数据逐只到达后再填入。清空或缺失的价格、成交额、开高低收、五档等数值显示为“—”，涨跌幅留空。

在自选页点击站点图标填写实际行情前置地址，例如 `tcp://你的主机:6402`，可用英文逗号分隔多个备用地址。示例代码中的 `10.0.1.101` 是内网示例，程序没有把它作为默认值。请确保电脑能访问行情服务器；没有地址时，股票页会显示接入提示。点击加号时先在三段选择器中选择沪、深或北，再输入六位股票代码。增删自选会在当前 TORA 连接上直接订阅或退订，无需重建行情连接。

行情 SDK 原始文件保存在 `vendor/PythonAPI_20260915/`。目前已验证此机器的 Python 3.14 x64 可以导入 SDK；实际行情连接与推送要在填写可访问的前置地址后验证。

## 验证

```powershell
python -m unittest -v
```

源码运行前执行 `python -m pip install -r requirements.txt`，以启用磨砂背景和抗锯齿圆角。热榜和 TORA 行情连接需要网络。重新构建时再安装 PyInstaller，运行 `./build.ps1`；脚本会把 Pillow、TORA SDK 及原生 `_xmdapi.pyd` 一起包含。仓库只提交源码；构建前需将用户提供的 TORA SDK 解压到 `vendor/PythonAPI_20260915/`，并将 mpv Windows x64 包里的 `mpv.exe`、`vulkan-1.dll` 放入 `vendor/mpv/`。

内嵌视频使用 [mpv](https://mpv.io/) Windows 构建；当前使用 [mpv v0.42.0 开发版 Windows x64 包](https://github.com/mpv-player/mpv/releases/download/git-release/mpv-v0.42.0-dev-gfe753a782-43295607237-x86_64-pc-windows-msvc.zip)。许可证见 `vendor/mpv/LICENSE.GPL`，源代码见 [mpv-player/mpv](https://github.com/mpv-player/mpv)。
